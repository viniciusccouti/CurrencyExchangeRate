# CurrencyExchangeRate

Sketch of a currency converter desktop app, not finished.

## Status

`main.py` only contains the plan, written as comments, and the `customtkinter` import. No window, conversion or exchange rate lookup has been implemented yet.

The planned design:

- A 500 x 500 window with a title.
- Two dropdowns to choose the source and the target currency.
- A "convert" button.
- A list showing the currency names.

## Requirements

Python 3 with `customtkinter`.

## Next steps

Build the window, load exchange rates from a source (an API or a file) and implement the conversion.
